Aviso 手动验收页

验收清单 A · 右键菜单
  1. 右键下方图片 → 菜单应出现「解释这张图片」
  2. 点击「解释这张图片」→ 浮窗出现；未配置 Key 时显示「API Key 未配置」
  3. 选中下方文字段落后右键 → 标题应显示选中文本预览（前 20 字）
  4. 右键下方链接 → 「总结」项应显示「总结这个链接」
  5. 右键页面空白处 → 「总结当前页面」→ 浮窗摘要应基于本页正文而非仅 URL
  6. 切换模型 radio → 重新打开右键菜单，勾选项应保持上次选择
验收清单 B · 划词工具栏
  1. 选中下方文字（≥2 字）→ 上方浮出工具栏：解释 / 翻译 / 润色 / 总结 / 发给 AI
  2. 点击各按钮 → 浮窗出现并流式输出；「发给 AI」进入自由对话
  3. Popup 常规页关闭「划词浮动工具栏」→ 再次选中文字不再浮出工具栏
验收清单 C · 命令面板（Mac: Command+Shift+Space / Win/Linux: Ctrl+Shift+Space）
  1. Mac 按 Command+Shift+Space，Win/Linux 按 Ctrl+Shift+Space → 面板居中弹出，输入框自动聚焦；Esc / 点遮罩关闭
  2. 输入关键词 → 搜索已保存历史与书签；↑↓ 导航、Enter 选择
  3. 当前 Chrome Profile 已保存 YouTube 书签时，输入 youtube → 结果中显示带「书签」标记的 YouTube 书签；点击后打开 URL
  4. 无结果时显示「没有找到已保存历史或书签，按 Enter 发给 AI」；回车仍按意图调用 AI（如「翻译 hello」应走翻译）
  5. 书签查询失败时显示「书签搜索失败，请检查扩展权限或重新加载扩展」，不应一直停在「搜索中…」
  6. 选中已保存历史项 → 以其原始操作重新执行（非固定解释）
  7. Popup 关闭「命令面板」→ 快捷键不再唤起
验收清单 D · 剪贴板感知
  1. 复制下方普通文字（≥5 字）→ 右下角 Toast 提示类型，3 秒后消失
  2. 复制「13800138000」「password: x」等敏感内容 → 不应弹 Toast
  3. Popup 关闭「剪贴板感知」→ 复制不再弹 Toast
验收清单 E · 自定义模板
  1. Popup → 模板页 → 添加模板：名称任意，内容含 {{selection}}，勾选「选中文字」→ 完成 → 保存设置
  2. 选中下方文字右键 → 「自定义模板 ▸」子菜单应出现刚建的模板
  3. 点击该模板 → 浮窗输出应基于选中文字（占位符已展开）
  4. 编辑 / 删除模板后保存 → 右键菜单即时同步（无需重装扩展）
验收清单 F · 浮窗与历史
  1. 浮窗「复制」可复制结果；「保存」后按钮变「✓ 已保存」，重复点击不重复入库
  2. 浮窗「继续追问」携带上文发起新请求并流式输出
  3. Popup → 历史页：可查看 / 置顶 / 删除 / 清空
验收清单 G · iframe / Hugging Face Spaces / Gradio 嵌入页
  1. 在本页底部 iframe 内选中文字 → iframe 内应浮出划词工具栏
  2. 点击 iframe 内工具栏的「解释 / 翻译」→ 顶层页面只出现一个 AI 浮窗；未配置 Key 时显示「API Key 未配置」
  3. 在 iframe 内选中文字后右键 → Aviso 菜单项可点击，点击后顶层页面只出现一个 AI 浮窗
  4. 聚焦 iframe 内输入框或正文后，Mac 按 Command+Shift+Space、Win/Linux 按 Ctrl+Shift+Space → 顶层页面只出现一个命令面板
  5. 在 iframe 内选中文字后按 Ctrl+C / Command+C → 顶层页面右下角出现剪贴板 Toast
  6. 反复按快捷键或重复点击 iframe 内工具栏，不应出现多个重复命令面板或多个浮窗实例
