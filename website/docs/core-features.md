# 核心功能

Aviso 当前重点是把常见网页对象接入 AI，并把结果留在当前页面。公开安装状态仍以 Chrome Web Store 审核结果为准。

## AI 服务路径

Aviso 支持两条 AI 服务路径：

- Aviso AI：登录后可使用免费额度，适合快速开始。
- BYOK direct-provider：填写自己的模型 API Key，浏览器扩展直接请求所选 provider，不强制登录。

只有用户选择 Aviso AI 并登录后，请求才会经过 Aviso 后端和上游模型 provider；BYOK 配置和直连请求不受 Aviso AI 登录状态影响。

## 右键菜单

右键菜单支持多种网页上下文：

- 选中文本：解释、翻译、润色、总结。
- 当前页面：提取页面正文后总结。
- 链接：把链接 URL 作为上下文交给 AI。
- 复制当前上下文：把页面标题、URL、可选选中文本和截断正文写入剪贴板，不调用 provider，适合继续提问、整理笔记或转给团队讨论。
- 图片：在右键内部路径中，对支持的图片地址或支持格式的 base64 图片数据发起解释；当前不作为普通用户主入口。
- 自定义模板：使用你在 Popup 中配置的提示词模板。
- 模型切换：从右键菜单快速切换当前模型。

## 划词工具栏

选中文字后，Aviso 会在页面内显示轻量工具栏。它适合快速处理当前读到或正在编辑的一小段内容。

可用操作包括解释、翻译、润色、总结和发给 AI。

## 划词翻译卡

划词翻译卡默认关闭。开启后，短选区可以就地显示翻译结果，并支持复制、重试和打开结果面板。

翻译 payload 只使用选区或用户输入的待翻译文本，不混入页面 URL、页面正文、远端链接正文、截图或剪贴板内容。

翻译目标语言可以在 Popup 中设置；它和界面语言互相独立。

## 命令面板

命令面板适合键盘用户：

- 搜索本地历史。
- 搜索 Chrome 书签。
- 搜索 Chrome 浏览历史。
- 搜索 Aviso 本地 AI 对话。
- 没有结果时把输入内容发送给 AI，或按本地意图生成候选。
- 打开 URL、打开历史/书签候选、翻译当前页面和总结当前页面时，必须先选择候选确认。
- 从历史项继续使用原始操作。

Mac 使用 `Command+Shift+Space`，Windows/Linux 使用 `Ctrl+Shift+Space`。

命令面板不展示截图入口。

命令面板不做自主浏览、联网搜索或远端链接正文抓取；浏览历史、书签和本地 AI 对话只作为本地候选。

## 双击快捷菜单

双击快捷菜单默认关闭。开启后，它会在普通网页区域提供紧凑入口，并避开输入框、可编辑区域、常见代码编辑器和 Aviso 自身 UI。

双击快捷菜单复用现有本地动作和 AI 动作，包括复制当前上下文、页面总结、常用模板、翻译、解释、润色和总结选区；不展示截图入口。

## 剪贴板感知

复制普通文本后，Aviso 可以显示提示，让你快速把剪贴板内容交给 AI。

Aviso 会跳过敏感域名和敏感内容，减少误处理密码、密钥、支付、后台管理等高风险信息的可能性。

## 页面内浮窗

浮窗是 Aviso 的主要结果展示位置。它会尽量在触发后立即出现，并显示读取页面内容或连接模型的等待状态。

浮窗支持复制结果、保存结果、去重保存和继续追问。

本地历史保存在浏览器本地扩展存储中。保存后的对话可以在命令面板和 Popup 中复用。

## Popup 设置页

Popup 用于管理：

- 界面语言。
- 外观主题。
- 默认模型和默认 AI 服务。
- 多 AI 服务配置。
- API Key。
- OpenAI / Anthropic / DeepSeek / Kimi-Moonshot / OpenRouter / Gemini / Tencent Hunyuan 模型 ID。
- 豆包 / Volcengine Ark 接入点和模型字段。
- Aviso AI 账号登录、刷新、退出、账号状态和额度状态。
- 功能开关。
- 翻译目标语言。
- 自定义模板。
- 历史记录。
- 隐私说明。

UI 支持中文 / English，默认跟随 Chrome 界面语言，也可以在 Popup 中手动覆盖。翻译目标语言和 UI 语言互相独立。

## Iframe 场景

Aviso 已支持常见 iframe 页面中的划词工具栏、右键触发和命令面板桥接，并尽量只在顶层页面显示一个浮窗。

更复杂的嵌入页面、跨域页面和动态应用仍建议继续作为持续观察范围。
