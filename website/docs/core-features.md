# 核心功能

Aviso v0.1 的重点是把常见网页对象接入 AI，并把结果留在当前页面。

## 右键菜单

右键菜单支持多种网页上下文：

- 选中文本：解释、翻译、润色、总结。
- 当前页面：提取页面正文后总结。
- 链接：把链接 URL 作为上下文交给 AI。
- 图片：在右键内部路径中，对支持的图片地址或支持格式的 base64 图片数据发起解释；当前不作为普通用户主入口。
- 自定义模板：使用你在 Popup 中配置的提示词模板。
- 模型切换：从右键菜单快速切换当前模型。

## 划词工具栏

选中文字后，Aviso 会在页面内显示轻量工具栏。它适合快速处理当前读到或正在编辑的一小段内容。

可用操作包括解释、翻译、润色、总结和发给 AI。

## 命令面板

命令面板适合键盘用户：

- 搜索本地历史。
- 搜索 Chrome 书签。
- 没有结果时把输入内容发送给 AI。
- 从历史项继续使用原始操作。

Mac 使用 `Command+Shift+Space`，Windows/Linux 使用 `Ctrl+Shift+Space`。

## 剪贴板感知

复制普通文本后，Aviso 可以显示提示，让你快速把剪贴板内容交给 AI。

Aviso 会跳过敏感域名和敏感内容，减少误处理密码、密钥、支付、后台管理等高风险信息的可能性。

## 页面内浮窗

浮窗是 Aviso 的主要结果展示位置。它会尽量在触发后立即出现，并显示读取页面内容或连接模型的等待状态。

浮窗支持复制结果、保存结果、去重保存和继续追问。

## Popup 设置页

Popup 用于管理：

- 模型选择。
- API Key。
- 豆包 / 火山方舟接入点和模型字段。
- 功能开关。
- 自定义模板。
- 历史记录。
- 隐私说明。

## Iframe 场景

Aviso 已支持常见 iframe 页面中的划词工具栏、右键触发和命令面板桥接，并尽量只在顶层页面显示一个浮窗。

更复杂的嵌入页面、跨域页面和动态应用仍建议继续作为内部试用观察范围。
