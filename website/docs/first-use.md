# 首次使用

安装后，可以先选择不包含隐私信息的公开页面，确认基础流程正常。你可以登录 Aviso AI 使用免费额度，也可以添加自己的 API Key 使用 BYOK provider。

## 先选择 AI 服务

### 方式一：登录 Aviso AI

1. 点击 Chrome 工具栏中的 Aviso 图标。
2. 在 Popup 中打开 AI 服务区域。
3. 点击登录 Aviso AI。
4. 登录完成后，确认账号状态和免费额度显示正常。
5. 回到网页中使用划词、右键或命令面板发起操作。

### 方式二：添加自己的 API Key

1. 点击 Chrome 工具栏中的 Aviso 图标。
2. 在 Popup 的 AI 服务区域新增或编辑一个 provider 配置。
3. 输入 API Key、模型 ID 或接入点。
4. 保存后可以设为默认服务。
5. 回到网页中使用划词、右键或命令面板发起操作。

BYOK 不需要登录 Aviso AI。Aviso AI 退出登录后，也不会删除你的 BYOK 配置。

## 方式一：选中文字后使用划词工具栏

1. 打开任意普通网页。
2. 选中一段文字。
3. 页面附近会出现 Aviso 划词工具栏。
4. 选择解释、翻译、润色、总结或发给 AI。
5. 查看页面内浮窗中的返回结果。

如果已开启划词翻译卡，短选区可以直接显示就地翻译结果，并支持复制、重试或打开结果面板。

如果经常翻译外文内容，可以先在 Popup 中设置翻译目标语言。翻译目标语言和界面语言互相独立。

## 方式二：使用右键菜单

选中文字、图片、链接或页面空白处后，可以通过右键菜单调用 Aviso。

常见操作包括：

- 解释选中文字。
- 翻译选中文字。
- 润色选中文字。
- 总结选区或当前页面。
- 复制当前上下文到剪贴板。
- 在已配置的模型之间切换。
- 使用自定义指令。
- 对支持的图片地址发起解释。
- 对链接 URL 发起总结提示。

链接总结会把链接本身作为上下文发送给模型。

复制当前上下文会把页面标题、URL、可选选中文本和截断正文写入剪贴板。这个动作本身不调用模型，也不会保存到历史。

## 方式三：打开命令面板

快捷键：

- Mac：`Command+Shift+Space`
- Windows/Linux：`Ctrl+Shift+Space`

命令面板可以搜索 Chrome 浏览历史、Chrome 书签和 Aviso 本地 AI 对话。没有搜索结果时，你也可以直接把输入内容发给 AI，或按本地意图生成候选。

打开 URL、打开历史/书签候选、翻译当前页面和总结当前页面都需要你先选择候选确认；命令面板不做自主浏览、联网搜索或远端链接正文抓取。

命令面板不展示截图入口。

## 方式四：使用双击快捷菜单

双击快捷菜单默认关闭。开启后，在普通网页区域双击可以显示一个紧凑入口，方便快速调用本地动作和 AI 动作。

Aviso 会避开输入框、可编辑区域、常见代码编辑器和 Aviso 自身 UI。双击快捷菜单不展示截图入口。

## 方式五：复制文本后的提示

复制普通文本后，Aviso 可以显示提示，方便你把剪贴板内容发送给 AI。敏感页面和敏感内容会被跳过，避免在高风险场景中误触发。

## 如果没有反应

可以先检查：

- 扩展是否已在 `chrome://extensions/` 中启用。
- 如果使用 Aviso AI，是否已登录、额度是否可用。
- 如果使用 BYOK，API Key 是否已保存，provider 账户是否可用。
- 当前网页是否允许扩展注入内容脚本。
- 对应功能开关是否开启。
- 模型是否只是响应较慢，而不是请求失败。

## 查看和保存结果

AI 返回结果会显示在当前页面内的 Aviso 浮窗中。浮窗支持：

- 流式展示结果。
- 复制结果。
- 保存到本地历史。
- 基于当前结果继续追问。
- 恢复已保存的本地对话。

历史记录保存在浏览器本地。
