# 首次使用

安装并设置 API Key 后，可以从一个普通网页开始试用。建议先选择不包含隐私信息的公开页面，确认基础流程正常。

## 方式一：选中文字后使用划词工具栏

1. 打开任意普通网页。
2. 选中一段文字。
3. 页面附近会出现 Aviso 划词工具栏。
4. 选择解释、翻译、润色、总结或发给 AI。
5. 查看页面内浮窗中的返回结果。

## 方式二：使用右键菜单

选中文字、图片、链接或页面空白处后，可以通过右键菜单调用 Aviso。

常见操作包括：

- 解释选中文字。
- 翻译选中文字。
- 润色选中文字。
- 总结选区或当前页面。
- 对支持的图片地址发起解释。
- 对链接 URL 发起总结提示。

链接总结会把链接本身作为上下文发送给模型。

## 方式三：打开命令面板

快捷键：

- Mac：`Command+Shift+Space`
- Windows/Linux：`Ctrl+Shift+Space`

命令面板可以搜索历史和书签。没有搜索结果时，你也可以直接把输入内容发给 AI。

## 方式四：复制文本后的提示

复制普通文本后，Aviso 可以显示提示，方便你把剪贴板内容发送给 AI。敏感页面和敏感内容会被跳过，避免在高风险场景中误触发。

## 查看和保存结果

AI 返回结果会显示在当前页面内的 Aviso 浮窗中。浮窗支持：

- 流式展示结果。
- 复制结果。
- 保存到本地历史。
- 基于当前结果继续追问。

历史记录保存在浏览器本地。
