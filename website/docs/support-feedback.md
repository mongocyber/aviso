# 支持反馈

Aviso 当前仍处于内部试用阶段。本页用于说明反馈时应包含哪些信息，以及哪些内容不要发送。

## 反馈前先确认

如果 Aviso 没有按预期工作，可以先确认：

- 扩展是否已在 `chrome://extensions/` 中启用。
- API Key 是否已保存，provider 账户是否可用。
- 当前网页是否允许扩展注入内容脚本。
- 是否在敏感页面或敏感内容场景中，导致剪贴板提示被跳过。
- 相关功能开关是否开启，例如划词翻译卡或双击快捷菜单。
- 模型是否只是响应较慢，而不是请求没有发出。

## 建议提供的信息

反馈问题时，建议提供：

- Chrome 版本。
- 操作系统。
- Aviso 版本。
- 触发方式：右键菜单、划词工具栏、划词翻译卡、双击快捷菜单、命令面板、剪贴板提示、页面内结果面板或 Popup。
- 使用的 provider 名称，但不要提供 API Key。
- 使用的模型或 AI 服务配置名称，但不要提供 API Key。
- 问题出现的页面类型，例如普通网页、iframe 页面、表单页面或图片页面。
- 可复现步骤。
- 可脱敏的截图或录屏。

## 不要提供的信息

请不要在反馈中发送：

- API Key、token、密钥或验证码。
- 私人网页正文。
- 客户资料、财务资料、合同、后台页面或未公开文档。
- provider 原始请求或响应全文。
- 含有真实账号、邮箱、手机号或付款信息的截图。

## 常见问题分类

| 现象 | 可能原因 |
| --- | --- |
| 浮窗出现但一直等待 | provider 响应慢、API Key 异常、网络问题或输入内容较长。 |
| 划词工具栏没有出现 | 页面禁止选择、内容在复杂 iframe 中、扩展未加载或功能开关关闭。 |
| 划词翻译卡没有出现 | 功能开关关闭、选区过长、当前页面不适合注入或 provider 不可用。 |
| 双击快捷菜单没有出现 | 功能开关关闭，或当前目标是输入框、可编辑区域、代码编辑器或 Aviso 自身 UI。 |
| 命令面板快捷键无效 | 系统快捷键冲突、浏览器焦点不在页面中，或扩展快捷键未生效。 |
| 命令面板搜索不到历史或书签 | 浏览器权限、搜索关键词、历史/书签数据或页面焦点可能影响结果。 |
| 链接总结不像正文总结 | 链接总结使用 URL 作为上下文。 |
| 图片解释失败 | 图片来源、格式、鉴权或 provider 下载能力受限。 |

## 反馈安全

反馈截图和录屏前请先脱敏，不要暴露 API Key、私人网页、真实账号、客户数据或未公开资料。
