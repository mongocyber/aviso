# 支持反馈

本页用于说明 Aviso 的反馈入口、反馈时建议包含的信息，以及哪些内容不要发送。

## 反馈入口

优先使用官网的 [反馈表单](/feedback/)。表单优先收集问题类型、触发方式、Chrome / OS / Aviso 版本、provider 路径和可选联系邮箱；提交后会通过官网邮件通道把结构化字段发送到维护者邮箱。可选补充说明用于用户整理上下文，但默认不会进入维护者邮件。

如果你是受邀测试者，也可以使用维护者单独提供的反馈渠道。GitHub Issues 仅适用于你已被授权访问仓库的情况。

## 反馈前先确认

如果 Aviso 没有按预期工作，可以先确认：

- 扩展是否已在 `chrome://extensions/` 中启用。
- 如果使用托管账号候选路径，是否处于 owner-gated 激活环境，账号或计划/额度状态是否可用，是否尝试过刷新账号状态。
- 如果使用 BYOK，API Key 是否已保存，provider 账户是否可用。
- 当前网页是否允许扩展注入内容脚本。
- 如果问题是剪贴板提示，是否已在 Popup 开启剪贴板感知，以及是否在敏感页面或敏感内容场景中被跳过。
- 相关功能开关是否开启，例如划词翻译卡或双击快捷菜单。
- 模型是否只是响应较慢，而不是请求没有发出。

## 反馈表单支持

官网反馈表单支持：

- 必填问题类型，例如功能问题、使用建议、安装问题或隐私权限。
- 必填触发方式，例如右键菜单、划词工具栏、划词翻译卡、双击快捷菜单、命令面板、剪贴板提示、页面内结果面板、Popup、安装 / 设置、官网 / 文档或其他。
- Chrome 版本、操作系统、Aviso 版本、provider 路径和可选 provider / 模型名称。
- 可选预期结果、实际结果、复现步骤和补充说明；这些字段如果看起来有风险，或按当前策略默认省略，可能不会转发到维护者邮件。
- 截图上传暂时关闭；反馈邮件默认不转发附件内容。
- 可选联系邮箱，便于维护者回复。

## 建议写入描述的信息

建议包含：

- Chrome 版本。
- 操作系统。
- Aviso 版本。
- 触发方式：右键菜单、划词工具栏、划词翻译卡、双击快捷菜单、命令面板、剪贴板提示、页面内结果面板或 Popup。
- 当前使用 Aviso AI 还是 BYOK provider。
- 使用的 provider 名称，但不要提供 API Key。
- 使用的模型或 AI 服务配置名称，但不要提供 API Key。
- 问题出现的页面类型，例如普通网页、iframe 页面、表单页面或图片页面。
- 可复现步骤。
- 可脱敏的截图或录屏说明；当前表单暂时不上传截图附件。

## 不要提供的信息

请不要在反馈中发送：

- API Key、token、密钥或验证码。
- 私人网页正文。
- 客户资料、财务资料、合同、后台页面或未公开文档。
- provider 原始请求或响应全文。
- 含有真实账号、邮箱、手机号或付款信息的截图。

## 常见问题分类

| 现象 | 可能原因 |
| --- | --- |
| 浮窗出现但一直等待 | Aviso AI 或 provider 响应慢、API Key 异常、网络问题或输入内容较长。 |
| 托管账号路径不可用 | 未处于 owner-gated 激活环境、账号或计划/额度状态不可用、账号状态需要刷新，或服务暂时不可用。 |
| 划词工具栏没有出现 | 页面禁止选择、内容在复杂 iframe 中、扩展未加载或功能开关关闭。 |
| 划词翻译卡没有出现 | 功能开关关闭、选区过长、当前页面不适合注入或 provider 不可用。 |
| 双击快捷菜单没有出现 | 功能开关关闭，或当前目标是输入框、可编辑区域、代码编辑器或 Aviso 自身 UI。 |
| 命令面板快捷键无效 | 系统快捷键冲突、浏览器焦点不在页面中，或扩展快捷键未生效。 |
| 命令面板搜索不到历史或书签 | 浏览器权限、搜索关键词、历史/书签数据或页面焦点可能影响结果。 |
| 链接总结不像正文总结 | 链接总结使用 URL 作为上下文。 |
| 图片解释失败 | 图片来源、格式、鉴权或 provider 下载能力受限。 |

## 反馈安全

反馈截图和录屏前请先脱敏，不要暴露 API Key、私人网页、真实账号、客户数据或未公开资料。反馈表单默认只把结构化字段发送到维护者邮箱；可选自由文本和附件内容默认不进入邮件，如果看起来有风险会在提交结果中提示需要脱敏。

## 支持入口

- 当前公开反馈入口优先使用 [官网反馈表单](/feedback/)。
- 如果你是受邀测试者，也可以使用维护者提供的反馈渠道。
