# 产品介绍

Aviso 是一个 Chrome 浏览器扩展，适合在阅读、研究、编辑网页内容时快速调用 AI。你可以对选中文字、当前页面、链接、图片线索、剪贴板内容、浏览历史和书签发起解释、翻译、润色、总结或自定义提示词操作，结果会显示在当前页面内的浮窗里。

Aviso 的核心目标不是替代完整聊天工具，而是减少来回复制粘贴：当你正在看网页、写内容或整理资料时，可以直接在当前上下文里处理手边的信息。

## 当前状态

Aviso 当前版本为 `0.1.0`，定位是内部试用版。核心功能已经实现，并已有 A-G 手动验收基本通过的内部记录；豆包 / 火山方舟 API 路径已有用户可用反馈。

当前状态：

- Aviso 当前安装方式是内部试用加载说明。
- 豆包 / 火山方舟 API 路径已有用户可用反馈。
- OpenAI 和 Anthropic 的真实调用保持在待验收状态。
- 本站说明当前内部试用版的已实现能力和使用边界。

## 适合谁使用

Aviso 适合经常在浏览器里处理信息的人，例如：

- 阅读英文资料并需要快速翻译或解释。
- 编辑网页文本、邮件、表单或草稿，需要润色表达。
- 研究网页、链接、书签和历史记录，希望快速提取线索。
- 希望用自己的 API Key 调用模型，并清楚数据会发送到所选模型 provider。

## Aviso 的使用边界

AI 请求由浏览器扩展直接发送给你选择的模型 provider。API Key、设置和历史优先保存在本地浏览器。

这意味着：

- 你需要自行准备 provider API Key。
- provider 的计费、数据处理和服务条款由你与 provider 之间的账户关系决定。
- Aviso 不承诺模型响应一定很快，首段返回速度会受网络、模型、输入长度、provider 状态和 API Key 状态影响。
- Aviso 目前不抓取任意远端链接正文，也不请求广域网页访问权限。
