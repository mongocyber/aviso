# 已知限制

Aviso 当前是 v0.1 内部试用状态。以下限制是有意保守记录，不应在公开材料中省略或改写成已解决。

## Provider 响应速度

Aviso 会尽量在触发后立即显示浮窗和等待状态，但模型首段返回速度仍取决于：

- 选择的模型。
- 网络状态。
- API Key 是否有效。
- provider 负载。
- 输入内容长度。
- 页面正文复杂度。

Aviso v0.1 不承诺模型秒回。

## 页面总结长度

页面总结会提取当前页面正文，并默认截断到约 5000 字符后再发送给 provider。

这能减少请求体积和等待时间，但长页面后半部分可能没有被完整覆盖。

## 远端链接正文

链接总结当前主要把链接 URL 作为上下文交给模型，不会主动抓取远端网页正文。

如果未来要抓取任意远端链接内容，通常需要扩大 host permissions。这属于单独的产品和隐私决策，不在 v0.1 当前范围内。

## 图片解释

Aviso 会对支持的图片 URL 或支持格式的 base64 图片数据发起解释。部分远端图片即使格式看起来可用，也可能因为 provider 无法下载、网页鉴权、跨域策略或图片来源限制而失败。

更可靠的任意网页图片解释方案需要另行评估浏览器本地截图或转换方案。

## Provider 验证状态

当前记录中：

- 豆包 / 火山方舟 API 路径已有用户可用反馈。
- OpenAI 真实调用尚未正式验证。
- Anthropic 真实调用尚未正式验证。

公开发布前，不应把 OpenAI 或 Anthropic 写成已验证 provider。

## 发布前门禁

以下事项仍未关闭：

- Chrome Web Store 公开提交。
- 最终 package zip。
- 商店截图、描述、发布说明和隐私声明。
- OpenAI / Anthropic 最小真实调用验证。
- 发布 tag。
- 回滚点记录。
- 最终权限和密钥泄露检查。

这些事项完成前，Aviso 应继续被描述为内部试用版或发布准备状态。
