03 System Summary

设计系统规范摘要

只保留迁移决策需要的核心要求；详细数值应在 owner 确认后进入正式设计系统文档。

颜色

Sage 是唯一品牌主色；浅色用 paper / ink，深色用 d-bg / d-surf；warn / danger 只用于真实风险。

字体与字号

界面使用 Hanken Grotesk；标签、代码、快捷键使用 Space Mono。运行态组件主要集中在 12-16px。

圆角与阴影

按钮 9px，菜单约 11px，面板 14-16px；阴影使用冷绿黑和负扩散，强调浮层边界。

动效

统一 cubic-bezier(.2,.8,.2,1)；hover/press 约 0.15s，toast 约 0.25s。

Logo / Mark

Aperture mark 保持单色，浅底用 ink/sage，深底用 white/sage；不要加渐变、阴影或复杂背景。

品牌语气

自然、克制、清楚。不夸大 AI 能力，不宣称未验证 provider、未上架状态或不存在的 hosted Aviso AI。

05 Code Mapping

和现有代码的对应关系

当前代码已经有共享 token、Mark、Icon，但组件 JSX 和样式散落在各运行入口里。 后续抽象应先不改变行为，只提取稳定 UI 单元。

src/styles/aviso.tsx 已承载 token、主题解析、Icon、Mark。 适合继续作为 token/brand 基础；后续可把 brand 组件移到 src/components/brand，但不要先动。
src/contents/toolbar.tsx 划词工具条、内联翻译卡片、选区定位。 适合抽 SelectionToolbar、InlineTranslationCard 到 src/components/ui。
src/contents/double-click-menu.tsx 双击菜单、menu item、divider、disabled 状态。 适合抽 MenuSurface、MenuItem，保留事件和安全判断在原文件。
src/contents/floating.tsx 结果面板、消息气泡、操作栏、追问输入、加载状态。 适合抽 ResultPanel、PanelHeader、PanelActions、LoadingMessage。
src/contents/command.tsx 命令面板 shell、输入行、结果行、AI 状态。 适合抽 CommandPaletteShell、CommandResultRow、StatusBadge。
src/contents/clipboard.tsx 剪贴板 toast、copy-context toast、计时条。 适合抽 Toast 和 ToastAction，保留隐私过滤与剪贴板逻辑。
src/popup/index.tsx Popup shell、tabs、provider cards、dropdown、toggles、history。 适合抽 PopupShell、Tabs、ToggleRow、ProviderCard，但必须分阶段做。
06 Execution Order

迁移后执行顺序

docs-only 迁移 owner 确认后，只把设计系统文档、Logo 说明、组件说明迁入规划/设计文档区，不改 runtime。
token 对齐 对比外部 tokens.css 与 src/styles/aviso.tsx，只做明确差异清单；是否修改由 owner 再确认。
组件抽象 新建 src/components/ui 和 src/components/brand 前先做设计/接口 plan，再按单组件小步提取。
逐步替换旧调用 按 toolbar、floating、command、clipboard、double-click、popup 的顺序逐个替换并验证，不做一次性大重写。
