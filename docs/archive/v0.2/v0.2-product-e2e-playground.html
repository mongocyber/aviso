Aviso v0.2 产品端到端测试现场

面向现场产品验收的高密度页面，覆盖命令面板、模板、选区、右键、剪贴板、iframe、readability、provider 边界和升级后本地数据保留。它是 implementation candidate 的测试工具，不代表 release ready。

状态：implementation candidate 发布：owner release decision pending 构建：Plasmo 默认，WXT 并行 Provider：不做 live validation 记录：本页 localStorage

测试边界

推荐从仓库根目录启动本地 HTTP 服务后打开： http://127.0.0.1:8765/docs/archive/v0.2/v0.2-product-e2e-playground.html。直接 file:// 打开时，Chrome 扩展需要允许访问文件 URL。

本页没有第三方脚本、遥测、网络请求或 provider 调用。现场测试也不要记录 API Key、raw prompt、raw provider response、私人页面正文、截图/base64、剪贴板原文或完整敏感 URL。

Provider 配置支持不等于 live validation；连接测试只能由 owner 明确手动触发，并且只做 summary-only 记录。

验收摘要

每项记录 pass / fail / blocked / note。本页会对摘要中的明显 Key、手机号、password 和完整 URL 做基础脱敏；默认摘要不包含测试正文或敏感样例原文。

现场素材

存储事实 非敏感设置位于 chrome.storage.sync/contextai_settings；模板和 providerConfigs 属于 settings。
API Key 边界 Key 位于 chrome.storage.local/contextai_api_keys，provider config key 在 providerConfigKeys；不要读取或打印值。
历史边界 本地对话历史位于 chrome.storage.local/contextai_history；不要把私人正文写进报告。
升级保留口径 同一扩展 ID 更新应保留本地数据；换成新扩展 ID 或 WXT unpacked 并行 ID 时，不应误判为同一扩展更新丢数据。

Readability / 页面总结素材

Aviso v0.2 端到端验收短文

Aviso v0.2 的当前目标是在不引入项目方后端、账号体系、订阅、遥测或 provider proxy 的前提下，让浏览器内的 AI 操作更可控。

命令面板应保持 local-first：历史、书签和本地 AI 对话只用于本地候选；打开网页、页面总结和页面翻译都需要用户确认。

Provider 扩展代表配置支持，不代表真实 live validation。当前默认构建仍是 Plasmo，WXT 只是并行路径。

iframe fixture

本 iframe 引用仓库既有测试页，适合本地 HTTP 打开后验证 iframe 内划词、右键、快捷键桥接、剪贴板和单实例 UI。
