# Aviso v0.2 Deferred Provider Decision Pack

Status: docs-only decision prep / no provider implementation / no new host permissions / no live validation
Updated: 2026-06-12

## Purpose

This pack turns the remaining deferred provider questions into owner decisions. It does not implement Qwen / DashScope or Zhipu GLM, does not add provider ids, does not add manifest host permissions, and does not run live provider calls.

Source baseline:

- `docs/archive/v0.2/v0.2-provider-batch2-preflight.md`
- `docs/archive/v0.2/v0.2-provider-config-contract.md`
- `docs/archive/v0.2/v0.2-provider-batch2-validation.md`

## Current State

| Provider         | Current state         | Why not implemented                                                                                                                                                   |
| ---------------- | --------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Qwen / DashScope | deferred              | Official OpenAI-compatible mode has multiple region-specific endpoints. Aviso needs exactly one fixed region / host policy before adding a preset or host permission. |
| Zhipu GLM        | deferred / unresolved | Existing preflight did not close whether the shared OpenAI-compatible route shape is safe enough. It needs a route-shape decision before implementation.              |

## Decision 1: Qwen / DashScope Region Policy

Recommended default:

```text
Defer Qwen / DashScope until the owner explicitly chooses one region.
```

Owner choices:

| Choice              | Meaning                                                                                        | Implementation impact                                                                                                                                                                                  |
| ------------------- | ---------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `none`              | Keep Qwen / DashScope out of the current provider line.                                        | No code, no manifest host, no public copy.                                                                                                                                                             |
| `beijing-only`      | Use the Beijing / mainland China OpenAI-compatible endpoint candidate from existing preflight. | Future implementation may add provider id `dashscope`, base URL `https://dashscope.aliyuncs.com/compatible-mode/v1`, and host permission `https://dashscope.aliyuncs.com/*` only after owner approval. |
| `new-review-needed` | Re-check official docs and choose a different single fixed region later.                       | Docs-only review first; no implementation until the fixed host is approved.                                                                                                                            |

Not allowed:

- Add all DashScope regional hosts.
- Add workspace-scoped Singapore host patterns.
- Add arbitrary custom endpoint input.
- Mix API keys and endpoints across regions.

## Decision 2: Zhipu GLM Adapter Shape

Recommended default:

```text
Do a separate route-shape spike before any Zhipu GLM provider implementation.
```

Owner choices:

| Choice                | Meaning                                                                                          | Implementation impact                                                                                      |
| --------------------- | ------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------- |
| `defer`               | Keep Zhipu GLM out of the current provider line.                                                 | No code, no manifest host, no public copy.                                                                 |
| `route-shape-spike`   | Review request, streaming, response, error, and auth shape against the current adapter contract. | Docs/test spike only; still no provider id or host permission until the spike closes.                      |
| `approve-after-spike` | Only available after a successful route-shape spike.                                             | Future implementation may add a fixed preset and `https://open.bigmodel.cn/*` host permission if approved. |

Not allowed:

- Force GLM through the shared adapter without a route-shape decision.
- Merge coding endpoint behavior into the general chat preset.
- Enable provider-specific capabilities, reasoning, tools, image, or web-search behavior by default.

## Evidence Rules

- Configuration support is not live validation.
- Any future implementation must use one fixed provider id, one fixed base URL, and one fixed host permission per provider.
- Any future live validation requires separate owner authorization and summary-only evidence.
- No raw prompts, raw responses, API keys, provider dashboard data, private page text, screenshots/base64, clipboard content, full URLs, or raw provider errors may be recorded.
