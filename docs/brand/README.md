# Aviso 品牌参考

本目录保存 Aviso 的品牌和组件视觉参考文件，仅作为设计归档和后续样式调整参考，不作为生产代码入口。

## 文件

- `aviso-components-reference.html`：Aviso 组件视觉参考。
- `aviso-logo-final.html`：Aviso Logo 最终视觉参考。
- `assets/aviso-mark-ink.svg`：墨色 Logo mark 参考素材。
- `assets/aviso-mark-sage.svg`：鼠尾草绿色 Logo mark 参考素材。
- `assets/aviso-mark-white.svg`：白色 Logo mark 参考素材。
- `components/aviso-components.css`：Aviso 组件样式参考。
- `components/aviso-ui.js`：Aviso 组件交互参考。

## 使用方式

后续修改 Popup、页面内浮窗、划词工具栏、命令面板、Toast 等样式前，应先查看本目录中的参考文件，确保视觉语言、组件质感和品牌表达一致。

不要直接把这些参考 HTML、CSS 或 JS 当成运行时代码复制进扩展。实际实现应继续沿用当前项目的 React / Plasmo 组件结构，并把参考样式转化为项目内可维护的组件和样式。
