Retrieval-augmented generation

Retrieval-augmented generation (RAG) is a technique that grants generative AI models information retrieval capabilities.

It modifies interactions with a large language model so that the model responds to user queries with reference to a specified set of documents, using this information to supplement its pre-trained knowledge.

This allows the model to use domain-specific or updated information without retraining.
