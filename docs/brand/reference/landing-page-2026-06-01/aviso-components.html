09Failure States · 友好失败提示

语气克制、清楚、不卖弄、不让人愧疚。先说发生了什么,再给一步可执行的出路。中性问题用 sage,真正的危险才升级配色。

还没连接到你的 AI

在设置里填入 API Key 就能开始,几秒就好。Key 只存在本地,绝不上传。

网络没接上

请求没能送达。检查一下连接,然后再试一次。

请求有点密集

当前模型暂时限流了。等几秒再发一次,通常就好了。

这段内容有点短

只选到了一小段,可能不足以总结。补充更多内容,或直接发给 Aviso 自由提问。

品牌语气 · 三条原则

  • 先说事,后给路。说明发生了什么,再给一步明确的下一步操作。
  • 克制,不亢奋。不为「AI」本身欢呼,把注意力留给用户的任务。
  • 清楚,不居高临下。「几秒就好」而不是「您只需简单几步即可轻松完成」。

微文案对照

  • ✓ 「还没连接到你的 AI」　✕ 「错误:未检测到有效的 API 凭证」
  • ✓ 「网络没接上,再试一次」　✕ 「哎呀!出错啦 😵 请稍后重试~」
  • ✓ 「已复制」　✕ 「太棒了!内容已成功复制到剪贴板!」
  • ✓ 「这段内容有点短」　✕ 「您选择的文本不符合最低字数要求」
  • ✓ 「Key 只存在本地」　✕ 「我们高度重视您的数据隐私安全」
