A. 截图

已修复，待重新加载扩展后复测

操作步骤

  1. 触发 Aviso 截图入口。
  2. 在图片区、空白区、页面底部和页面右侧分别拖选区域。
  3. 点击 Copy image，成功后粘贴到其他地方确认图片已复制。
  4. 再次选区，在选区内双击，验证直接复制图片并退出截图模式。
  5. 再次选区，在选区外双击，验证直接退出截图模式。
  6. 依次点击 Download image、Retry、Cancel。
  7. 再次选区后点击 Send to AI。
  8. 从双击菜单或命令面板点击截图快捷入口，确认只显示授权入口提示。
  9. 从右键菜单点击“截图提问”，确认仍可进入截图选区。

期望结果

  • 工具栏贴近选区底边居中位置。
  • 下方空间不足时，工具栏优先贴选区内底部居中；仍不足时再向上夹取。
  • 按钮是图标加文字，视觉权重一致，复制按钮不应有 primary 底色。
  • 按钮行在黑色底框内垂直居中；无错误文案时黑色底框不过高。
  • 出现错误文案时，底框可以被撑开，但按钮行仍应保持视觉居中。
  • 每个按钮都有可见状态或可读错误。
  • Copy 成功后退出截图模式；失败时保留选区并显示中文可执行错误。
  • 选区内双击等同 Copy；选区外双击等同 Cancel，且不触发双击快捷菜单。
  • 页面内截图快捷入口只提示用户改用扩展入口，不直接开始截图框选。
  • 右键菜单“截图提问”保留为推荐的授权截图入口。
  • Copy / Download 为 local-only，不要求登录、不消耗额度、不调用 provider。

B. 划词工具栏

当前预期：点击按钮触发

操作步骤

  1. 选中“可选中文本”区域中的中文或英文。
  2. 确认划词工具栏出现。
  3. 点击“翻译”。
  4. 再测试解释、润色、总结、发给 AI。

期望结果

  • 选中文字后出现工具栏。
  • 点击“翻译”仍可进入现有翻译流程。
  • 开启“内联即时翻译”后，短选区可自动显示内联翻译卡片。
  • 普通拖选 / 普通选中文本仍应显示划词工具栏。
  • 如果本轮双击菜单已经显示，划词工具栏不应同时出现。
  • 翻译输入只应是选中文本，不应混入 URL、页面正文、截图或剪贴板。

D. 双击菜单

默认关闭，待开启后复测

操作步骤

  1. 在设置里开启“双击快捷菜单”。
  2. 双击普通文本，确认菜单出现，且划词工具栏不同时出现。
  3. 关闭菜单后普通拖选文本，确认划词工具栏仍可出现。
  4. 双击输入框、文本框、代码或可编辑区域，确认双击菜单不触发。
  5. 测试菜单里的截图、复制上下文、页面总结和选区动作。

期望结果

  • 开关默认关闭。
  • 安全文本区域双击才显示菜单。
  • 双击菜单显示时，本轮交互不重复显示划词工具栏。
  • 禁用区域不显示双击菜单，也不错误抑制正常选择行为。
  • 双击菜单关闭后，后续普通选中文本仍可显示划词工具栏。
  • 打开菜单本身不调用 provider。
  • 菜单动作复用现有路径，不新增权限或后端。
