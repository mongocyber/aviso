## 1. M1 · 主链路打磨

接管基线状态：✅ 代码项已完成；✅ 用户反馈 A-G 基本通过；⚠️ 公开发布前需补齐环境证据。

- [ ] 右键选中文字后可解释、翻译、润色、总结，并出现浮窗。
- [ ] iframe 内右键选中文字后，Aviso 菜单点击可在顶层页面打开唯一 AI 浮窗。
- [ ] 右键当前页面总结时，结果基于当前页正文而非仅 URL。
- [ ] iframe 内右键页面总结时，正文抽取优先来自被点击的 iframe frame。
- [ ] 右键链接总结时菜单存在；结果当前仍只基于 URL。❌ 远端链接正文抓取不在当前最小权限范围内。
- [ ] 右键图片可触发图片解释。
- [ ] 模型 radio 选择会保存，菜单重建后勾选项保持一致。
- [ ] Popup 关闭划词工具栏后，划词工具栏不再出现。
- [ ] iframe 内选中文字后可出现划词工具栏；点击解释/翻译/润色/总结/发给 AI 后，AI 浮窗统一显示在顶层页面，不重复创建多个浮窗。
- [ ] Popup 关闭命令面板后，快捷键不再唤起面板。
- [ ] Popup 关闭剪贴板感知后，复制文本不再弹 Toast。

## 4. M4 · 健壮性与隐私

接管基线状态：✅ 代码项已完成；⚠️ 待发布前复核。

- [ ] 未配置 API Key 时触发 AI 操作，浮窗显示可读错误，而非白屏或卡死。
- [ ] 网络失败、限流、无效 Key 等错误显示归一后的中文提示。
- [ ] 用户触发 AI 操作后，前端浮窗应立即出现，并显示“正在读取页面内容…”或“正在连接模型…”等明确等待状态。
- [ ] 控制台 `[Aviso timing]` 日志能区分触发、浮窗显示、background 接收、provider 请求开始、first chunk 和 done。
- [ ] 剪贴板敏感域名和敏感内容过滤有单元测试覆盖。
- [ ] Manifest 权限与实际功能匹配，不扩大浏览器权限或广域 host 权限。
- [ ] Popup 隐私说明与实际数据流一致：无自建后端、无遥测、API Key 本地加密保存。
- [ ] 页面正文传入模型前有长度限制；v0.1 默认按 5000 字符截断。

## 已知限制

1. 远端链接正文总结未实现，因为它通常需要扩大 `host_permissions`，当前产品原则仍是最小权限。
2. 前端响应链路已优化：触发后浮窗应立即出现，并显示明确等待状态。
3. provider 首 token 仍可能受模型、网络、API Key 状态、provider 负载、输入长度和页面正文复杂度影响。
4. Aviso v0.1 不承诺模型秒回；当前不做后端中转、不扩大权限、不新增依赖、不继续重构 AI 客户端。
5. 当前只有用户反馈的 A-G 基本通过记录；公开发布前仍需补录环境、截图或异常备注。
6. 当前没有真实 OpenAI / Anthropic 调用记录；豆包 / 火山方舟 API 用户确认可用，但仍建议补充结构化验证记录。
7. 商店素材和外部隐私政策页面仍需人工准备。
