## Runtime Entrypoints

WXT now has runtime entrypoints for the current extension surfaces:

| Surface | WXT entrypoint |
| --- | --- |
| Background service worker | `src/entrypoints/background.ts` |
| Popup | `src/entrypoints/popup/index.html`, `src/entrypoints/popup/main.tsx` |
| Selection toolbar | `src/entrypoints/toolbar.content.tsx` |
| Floating panel | `src/entrypoints/floating.content.tsx` |
| Command palette | `src/entrypoints/command.content.tsx` |
| Clipboard toast | `src/entrypoints/clipboard.content.tsx` |
| Double-click menu | `src/entrypoints/double-click-menu.content.tsx` |
| Screenshot internal path | `src/entrypoints/screenshot.content.ts` |
| Readability extraction | `src/entrypoints/readability.content.ts` |
| Iframe shortcut bridge | `src/entrypoints/frame-bridge.content.ts` |

React content-script surfaces are mounted through `src/wxt/react-shadow-ui.tsx`, preserving the current shadow host IDs used by the source content components.

Popup runtime uses `src/entrypoints/popup/index.html` plus manual React mount from `src/entrypoints/popup/main.tsx`. The popup source now supports WXT `#root` / `body > div` selectors while still keeping the temporary `#__plasmo` compatibility selector because Plasmo rollback remains in scope.

## Manifest Parity

Compared outputs:

- Plasmo: `build/chrome-mv3-prod/manifest.json`
- WXT: `.output/chrome-mv3/manifest.json`

Automated parity result:

| Field | Result |
| --- | --- |
| `permissions` | Same values: `contextMenus`, `activeTab`, `storage`, `history`, `bookmarks`, `clipboardWrite`. |
| `host_permissions` | Same values: `https://api.openai.com/*`, `https://api.anthropic.com/*`, `https://ark.cn-beijing.volces.com/*`. |
| `default_locale` | Same value: `zh_CN`. |
| `commands` | Same command and shortcut: `open-command-palette`, `Ctrl+Shift+Space`, `Command+Shift+Space`. |
| `action.default_popup` | Same value: `popup.html`. |
| `content_scripts` | Same runtime coverage. WXT groups scripts with equivalent `matches`, `all_frames`, and effective `run_at` values. |
| `icons` | WXT uses public icon paths generated from the existing Aviso icon. |

Intentional output difference:

- WXT adds `action.default_title: "Aviso"`.
- WXT groups content scripts into fewer manifest entries when their `matches`, `all_frames`, and effective `run_at` values are equivalent.

No new extension permissions or provider host permissions were introduced.
