# Aviso V02-WXT-001 WXT Migration Preflight

Status: Draft / owner review
Updated: 2026-06-11
Scope: docs-only preflight. No source, dependency, manifest, package, build default, provider, storage, permission, or release change is approved by this document.

## Current Baseline

Aviso is currently a Chrome MV3 extension built with Plasmo `0.90.5`, React 18, and TypeScript. The release state remains `v0.1 internal dogfood / 内部试用版`; `0.1.0` has been submitted to Chrome Web Store review, but is not publicly approved or listed.

Current usable AI model:

- BYOK direct-provider only.
- No Aviso backend, provider proxy, hosted AI, account, quota, subscription, payment, telemetry, analytics, remote link-body fetching, or web search.
- API keys stay in `chrome.storage.local/contextai_api_keys`; non-secret settings stay in `chrome.storage.sync/contextai_settings`.
- Screenshot remains an internal right-click path only. It must not become a command-palette or double-click primary entry during migration.

Current built Plasmo production manifest was available at `build/chrome-mv3-prod/manifest.json` and was used as a local parity reference. WXT official docs checked on 2026-06-11 show WXT `v0.20.26`; key migration rules are: entrypoints live under `entrypoints/`, manifest is generated from `wxt.config.ts` and entrypoint options, React popup needs an HTML entrypoint plus manual mount, content scripts use `defineContentScript`, and content script UI can use `createShadowRootUi`.

## Recommended WXT Shape

Use `srcDir: "src"` so existing source modules can remain under `src/` and WXT entrypoints can live under `src/entrypoints/`.

Recommended target layout:

```text
wxt.config.ts
tsconfig.json
public/
  _locales/
    zh_CN/messages.json
    en/messages.json
  icons/
    icon16.png
    icon32.png
    icon48.png
    icon64.png
    icon128.png
src/
  entrypoints/
    background.ts
    popup/
      index.html
      main.tsx
    frame-bridge.content.ts
    readability.content.ts
    floating.content.tsx
    double-click-menu.content.tsx
    screenshot.content.ts
    clipboard.content.tsx
    command.content.tsx
    toolbar.content.tsx
  background/
  contents/
  popup/
  styles/
  types/
  utils/
tests/
```

Notes:

- Keep implementation modules in their current `src/background`, `src/contents`, `src/popup`, `src/styles`, `src/types`, and `src/utils` locations where possible. Use thin WXT entrypoint wrappers first.
- Preserve Plasmo scripts as rollback in V02-WXT-002. Do not switch default `dev`, `build`, or `package` to WXT until V02-WXT-004 passes and owner approves.
- Existing imports use Plasmo-style `~types/...`, `~utils/...`, and `~styles/...`. WXT's default aliases are not enough for that exact import shape. V02-WXT-002 should either configure explicit WXT aliases for these prefixes in `wxt.config.ts`, or V02-WXT-003 should do a focused import rewrite. Prefer aliases first to reduce migration diff size.

## Current Manifest Parity Checklist

Use the Plasmo build manifest as the before side and WXT `.output/chrome-mv3/manifest.json` as the after side.

Global fields:

- [ ] `manifest_version` remains `3`.
- [ ] `name` remains `Aviso`.
- [ ] `version` remains `0.1.0` until a separate release/version decision.
- [ ] `author` remains `Aviso`.
- [ ] `description` remains `__MSG_app_description__`.
- [ ] `default_locale` remains `zh_CN`.

Permissions:

- [ ] `permissions` exactly remain `contextMenus`, `activeTab`, `storage`, `history`, `bookmarks`, `clipboardWrite`.
- [ ] `host_permissions` exactly remain `https://api.openai.com/*`, `https://api.anthropic.com/*`, `https://ark.cn-beijing.volces.com/*`.
- [ ] No `<all_urls>` host permission is added.
- [ ] No optional permissions, declarativeNetRequest, scripting, tabs, alarms, sidePanel, identity, downloads, notifications, or broad host wildcard is added unless separately approved.

Commands:

- [ ] `commands.open-command-palette.suggested_key.default` remains `Ctrl+Shift+Space`.
- [ ] `commands.open-command-palette.suggested_key.mac` remains `Command+Shift+Space`.
- [ ] Command description remains `__MSG_open_command_palette_description__`.
- [ ] No screenshot command is added.

Background:

- [ ] MV3 background service worker exists.
- [ ] Context menus register on install/start/service-worker-start equivalent to current behavior.
- [ ] `chrome.commands.onCommand`, `chrome.contextMenus.onClicked`, `chrome.storage.onChanged`, and `chrome.runtime.onMessage` behavior is preserved.
- [ ] If WXT emits `background.type: "module"`, that difference is explicitly reviewed against Chrome loaded-extension behavior before acceptance.

Popup/action:

- [ ] `action.default_popup` remains `popup.html`.
- [ ] Popup opens at the same functional size and scroll behavior.
- [ ] `action.default_icon` keeps 16, 32, 48, 64, and 128 icon entries.
- [ ] No options page, side panel, new tab override, or browser action behavior is added.

Icons/assets:

- [ ] Manifest `icons` keeps 16, 32, 48, 64, and 128 icon entries.
- [ ] Each referenced icon file exists in the WXT output.
- [ ] Icon source remains derived from `assets/icon.png` unless owner approves asset replacement.

Content scripts:

- [ ] `frame-bridge`: matches `<all_urls>`, `all_frames: true`, `run_at: document_start`.
- [ ] `readability`: matches `<all_urls>`, `all_frames: true`, `run_at: document_idle`.
- [ ] `floating`: matches `<all_urls>`, `all_frames: false`.
- [ ] `double-click-menu`: matches `<all_urls>`, `all_frames: true`.
- [ ] `screenshot`: matches `<all_urls>`, `all_frames: false`.
- [ ] `clipboard`: matches `<all_urls>`, `all_frames: true`.
- [ ] `command`: matches `<all_urls>`, `all_frames: false`.
- [ ] `toolbar`: matches `<all_urls>`, `all_frames: true`.
- [ ] Effective run timing for UI scripts remains Chrome default/equivalent if `run_at` is omitted.
- [ ] Script count and frame coverage remain equivalent; no content script is dropped or broadened.

Web accessible resources:

- [ ] WXT output should also have no `web_accessible_resources` unless a chosen UI strategy requires it.
- [ ] If `createIframeUi`, public content assets, or other WXT helpers require `web_accessible_resources`, the exact resources and matches must be reviewed as a stop-line before continuing.

Locales:

- [ ] WXT output contains `_locales/en/messages.json`.
- [ ] `app_description` messages remain unchanged.

## Loaded-Extension Smoke Checklist

This smoke is for V02-WXT-004 after WXT builds. It is not part of V02-WXT-001 execution. Unless owner separately approves live provider validation, run it without real provider calls and record provider-dependent steps as UI/path smoke only.

- [ ] Right-click menu: menu tree appears on selection, page, link/image where expected; model radio entries reflect configured AI services; custom templates appear where their contexts allow.
- [ ] Selection toolbar: selecting text shows toolbar in safe targets; explain/translate/polish/summarize/send actions open the result panel path without UI duplication; toolbar hides on scroll/Escape and avoids Aviso UI clicks.
- [ ] Inline selection translation: if enabled, short selection shows inline card; long or multiline selection falls back to result panel; copy/retry/send-to-AI controls render.
- [ ] Command palette: `Command+Shift+Space` on Mac and `Ctrl+Shift+Space` elsewhere opens top-frame palette; iframe shortcut routes through `frame-bridge`; history/bookmark/AI-history search remains local; unsafe URLs are blocked.
- [ ] Double-click menu: default-off state is respected; when enabled, double-click menu avoids inputs/editors/Aviso UI; copy context, page summary, selection actions, and templates appear correctly; no screenshot entry appears.
- [ ] Clipboard prompt: copying ordinary non-sensitive text shows toast; sensitive content and sensitive domains are skipped; iframe copy toast routes to top frame.
- [ ] Floating result panel: opens from toolbar/command/double-click/context paths, streams or shows blocked/error state, supports copy/save/stop/follow-up, and persists sanitized conversation history.
- [ ] Popup provider settings: popup opens, scroll height is stable, language/theme toggles work, AI service cards load existing configs, API keys stay masked, model ID is editable, manual connectivity button does not auto-run without user action.
- [ ] Screenshot right-click internal path: context-menu screenshot starts selection overlay, copy/download/reselect/cancel controls work, send-to-AI path opens result panel only when an approved model route supports image input; no screenshot entry exists in command palette or double-click menu.
- [ ] iframe/frame bridge: iframe selection toolbar, iframe copy prompt, iframe shortcut-to-command-palette, and display-frame routing avoid duplicate panels.
- [ ] i18n: Chrome manifest locale resolves `_locales` messages; runtime UI language can follow Chrome or be overridden to Chinese/English; user-saved provider names and prompt names are not translated.
- [ ] Theme isolation: light/dark/system theme applies to Popup and Aviso overlays without changing host page body/html styles.
- [ ] Privacy smoke: no console/log/output includes API keys, raw prompts, raw provider responses, private page bodies, screenshots/base64, full private URLs, or clipboard content.

## Stop Lines

Stop and return to CTO/owner before continuing if any of these happen:

- Any new or changed `permissions`.
- Any new or changed `host_permissions`.
- Any new broad wildcard permission, `<all_urls>` host permission, optional permission, or custom endpoint access.
- WXT scaffold requires deleting Plasmo rollback before manifest and loaded-extension parity are proven.
- WXT migration cannot preserve Shadow DOM/UI isolation or stable Aviso host containment.
- WXT content UI strategy requires `web_accessible_resources` that are not already reviewed and approved.
- WXT requires a dependency beyond `wxt` and required WXT/React support that has not been approved.
- WXT output manifest differs in content scripts, background, popup/action, icons, commands, default locale, locales, permissions, or host permissions without a written owner decision.
- Popup migration requires API key storage migration, storage key rename, or moving secrets into sync storage.
- Any task asks for real provider calls, live connectivity validation by the agent, reading/printing API keys, raw prompts, raw responses, private page body, screenshot/base64, full private URLs, or clipboard content.
- Any task asks to switch default build/package scripts to WXT before V02-WXT-004 passes.
- Any task asks to publish, tag, submit to Chrome Web Store, create GitHub Release, or publicly claim WXT migration is shipped.
