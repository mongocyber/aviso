## Scope

This closeout records the v0.2.1 default-build migration from Plasmo default scripts to WXT default scripts.

This is a build-chain slice only. It does not add product features, providers, permissions, host permissions, background services, telemetry, login, subscription, payment, custom base URL support, release tags, pushes, or Chrome Web Store submission.

This is not a rewrite of current v0.2 history. Current v0.2 remains recorded as keeping Plasmo default; this v0.2.1 slice is the separate default-build migration.
