Aviso v0.2 验收短文

Aviso v0.2 的目标是在不引入后端、账号、订阅、遥测和 provider proxy 的前提下，让浏览器扩展更开放、更快、更可控。用户继续使用自己的 API Key，扩展只直连已批准的 provider host。

命令面板的本地意图增强让用户可以搜索浏览历史、书签和本地 AI 对话，也可以明确选择页面总结、页面翻译或直接问 AI。所有打开网页和页面动作都应先出现候选，由用户确认后执行。

Provider 扩展支持 DeepSeek、Kimi / Moonshot、OpenRouter、Gemini 和 Tencent Hunyuan 的配置，但配置支持不等于 live validation。
