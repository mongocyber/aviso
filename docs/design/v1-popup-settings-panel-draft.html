Aviso Popup 设置面板优化草稿

目标是把当前偏开发者的设置页，改成普通用户能理解的控制面板：先看能不能用，再连接自己的 AI 服务，最后管理入口、记录和常用指令。

BYOK 连接自己的 AI 服务
对外不再说 BYOK。普通用户看到的是“我需要连接哪个 AI 服务”“现在是否可以使用”。

1. 首屏改为“设置”

第一个面板合并当前 AI 状态、模型选择、常用功能开关和选区翻译目标。用户打开后直接知道能不能用，也能马上切换模型和入口。

2. AI 服务只负责配置和测试

OpenAI、Anthropic、豆包分别成为配置卡片。这里只处理 API Key、豆包接入点和连接测试，不再承担默认模型选择。

Light theme reference

浅色模式不是反相深色主题。运行态应使用 paper / bg / surface2 三层背景，ink 文本，sage 作为唯一强调色；dropdown、footer、privacy panel、input、hover、disabled、warning、danger 都必须落在浅色 token 上。

3. 控件合并和降噪

功能开关改为紧凑设置行；内联翻译在同一行显示“选中文字译为 xx”；目标语言只保留右侧小下拉。

4. 记录默认自动保存

结果面板已经自动保存 conversation。历史面板只保留恢复、删除、清空全部，避免增加额外管理负担。

5. 已对齐现有 Popup 功能

默认 AI 模型 当前 AI 状态 选区翻译目标 核心功能开关 AI 服务连接 历史删除 指令删除

建议的实现顺序

  • 先改文案和面板信息架构，不动存储 schema。
  • 设置页模型下拉只出现已配置服务；未配置服务只在 AI 服务页出现。
  • 目标语言使用下拉控件，避免一组语言按钮占用太多高度。
