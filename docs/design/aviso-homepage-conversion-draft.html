Workflow

从选中，到答案，不离开这一页。

Aviso 的核心不是多一个聊天窗口，而是减少切换，把结果放回原文旁边。

Use cases

阅读、翻译、整理上下文，一套入口完成。

少写说明，多展示用户会装它的原因：少切页、少复制、少丢上下文。

读 解释重点 看技术文档、论文、长文章时，把难懂段落直接解释清楚。
译 即时翻译 短句就地翻译，复制或打开结果面板继续处理。
摘 页面总结 一键读取当前页面，生成摘要，再继续追问细节。
模 常用模板 把重复 Prompt 做成模板，从右键或命令面板触发。
